PLUGIN ECOSYSTEM

可复用的本地能力。一条命令先安装 CLI，再安装插件、通知 GQY 重新扫描并自动加载。

TRY IT NOW
$ go install github.com/GQYTeam/gqy-plugins/cmd/gqy-plugin@latest
$ gqy-plugin install <id> --server http://127.0.0.1:5173 --load

命令会先安装 CLI，再用 CLI 安装插件；安装完成后自动触发 reload 与 load。

HOW IT WORKS

卡片安装 = CLI 安装 + 自动加载

  1. 先安装 CLI。卡片命令第一步永远是 go install .../gqy-plugin@latest。
  2. 再安装插件。CLI 下载 Release / commit tarball，校验 SHA-256 后原子写入 $GQY_HOME/plugins/<id>/。
  3. 自动加载。--server http://127.0.0.1:5173 --load 会调用 /api/plugins/reload 与 /api/plugins/<id>/load。

卡片按钮只复制命令，不会在浏览器里执行本地程序。一次性插件（oneshot）不常驻安装，会在卡片上单独标记。
