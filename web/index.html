给 GQY 装上新的能力。

在线目录是唯一事实来源。每个安装包都带 SHA-256，安装时先校验、再解包、最后原子落盘。

go run github.com/GQYTeam/gqy-plugins/cmd/gqy-plugin@latest install <id>

安装之后

  1. 把插件放进 $GQY_HOME/plugins/<id>/。
  2. 让运行中的 GQY 重扫：POST /api/plugins/reload。
  3. 显式加载插件：POST /api/plugins/<id>/load。安装不等于自动执行。

也可以加 --server http://127.0.0.1:5173 让 CLI 自动通知本机 GQY；加 --load 才会请求加载。
