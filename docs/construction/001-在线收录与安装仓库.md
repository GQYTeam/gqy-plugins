# 001 · 在线收录与安装仓库

日期：2026-11-02
状态：已完成

## 目标

把 `gqy-plugins` 从空目录基线做成可用的插件在线收录与安装仓库：一个目录、一个 CLI、一个静态站，以及两条真实官方插件产物。安装必须校验 SHA-256 并原子落盘，默认不自动加载。

## 范围

**做：**

- `registry.json` 收录 `show-images-default@1.0.0` 与 `emote-pack-default@1.0.0`。
- 确定性打包器与真实 `.tar.gz` 产物。
- `gqy-plugin` CLI：`list / search / info / install / verify / package/version`。
- 安全解包、SHA-256、大小校验、原子安装与 force 回滚。
- 可选 GQY `/api/plugins/reload` 与 `/load` 通知。
- 静态目录站与 GitHub Pages 工作流。
- 设计、蓝图、协议参考与 README 更新。
- CI：gofmt / vet / test / build / node --check / strict registry verify。

**不做：**

- 签名、镜像、评分、付费、自动更新、运行时权限墙。
- GQY 主仓库内嵌市场 UI。
- 在线提交后台；收录继续走 PR。

## 施工顺序

1. 固定目录字段、版本选择与产物不可变规则。
2. 实现 `internal/registry` 的版本解析与 strict 校验。
3. 实现 `internal/manifest`、`internal/archive`、`internal/install` 与测试。
4. 实现 CLI 与 JSON 输出。
5. 打包两个官方插件，得到真实 SHA-256 与 size。
6. 创建 `v0.1.0` Release 并上传产物。
7. 把真实 Release URL 写进 `registry.json`，跑 `verify --artifacts`。
8. 实现静态站与 Pages 工作流；更新文档和 CI。

## 验收

```bash
make check
go run ./cmd/gqy-plugin list
go run ./cmd/gqy-plugin info show-images-default
go run ./cmd/gqy-plugin verify --strict
go run ./cmd/gqy-plugin verify --artifacts
go run ./cmd/gqy-plugin install show-images-default --plugins-dir /tmp/gqy-plugins-test
```

安装测试还应覆盖：重复安装报错、`--force` 成功且无备份残留、错哈希拒绝、路径穿越包拒绝、`oneshot` 拒绝。
