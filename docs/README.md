# 文档索引

`gqy-plugins` 的文档入口，按组织统一三层组织。改代码前先看对应文档；文档与代码不一致时，以代码为准并顺手更正文档。

| 目录 | 管什么 |
| --- | --- |
| [`designs/`](designs/README.md) | 定了什么、为什么、不做什么 |
| [`blueprint/`](blueprint/README.md) | 现在长什么样：目录字段、CLI、站点与测试 |
| [`construction/`](construction/README.md) | 一次改动怎么做、验收与留底 |
| [`reference/`](reference/README.md) | 对外协议字段与示例 |
